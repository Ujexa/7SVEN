# Security policy

7SVEN can use Android accessibility and other sensitive permissions. Do not include private messages, contacts, access tokens, passwords, phone numbers, or personal data in public bug reports.

For a suspected security issue, contact the maintainers through a private contact method listed on the Ujexa GitHub organization profile, if available. Until a private reporting address is published, avoid posting exploit details or sensitive user data in public issues.

This policy will be updated as the project matures.
