# Security policy

7SVEN can use Android accessibility and other sensitive permissions. Please do not include private messages, contacts, access tokens, passwords, phone numbers, or personal data in public bug reports.

For a suspected security issue, contact the maintainers through the private contact method listed on the Ujexa GitHub organization profile, if available. Until a private reporting address is published, do not post exploit details or sensitive user data in public issues.

Supported version: the latest published release, once releases are available. This policy will be updated as the project matures.
