# Contributing

Thanks for your interest in 7SVEN.

Before opening a pull request:
1. Explain the user-facing problem and intended behavior.
2. Keep changes small and focused.
3. Add or update JVM tests for deterministic logic.
4. For Android-specific behavior, include device/Android version, permissions, exact steps, expected behavior and observed behavior.
5. Never include model weights, APKs, signing keys, personal logs, private messages, or credentials.
6. Check third-party licensing before adding a library, model, or asset.

Accessibility and phone-action changes should fail safely, verify outcomes where possible, and require user confirmation for consequential actions. Do not describe a command as successful unless the app has evidence that it succeeded.
