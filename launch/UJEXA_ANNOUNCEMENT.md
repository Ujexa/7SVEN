## Introducing 7SVEN

7SVEN is Ujexa's local-first Android phone assistant project.

It brings together on-device language-model inference, phone tools, persistent memory, multi-step tasks, reminders, voice interaction and safety checks—with a focus on keeping core processing on the device.

The v1.4.1 development build has been tested on a physical Android phone for a set of core commands. The project is still evolving: accessibility behavior varies across apps and devices, some actions require user confirmation, and background scheduling can be affected by Android battery policies.

We're preparing the public source repository with build notes, test evidence, known limitations and third-party licensing information. This is an early release, and we welcome focused feedback and reproducible bug reports.
