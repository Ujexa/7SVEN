# 7SVEN v1.4.1 is now public

Today we're publishing 7SVEN, Ujexa's local-first Android phone assistant.

**What it does**
- Uses a local language model for assistant reasoning.
- Connects supported phone actions, persistent memory, multi-step tasks and reminders.
- Supports text and voice interaction with safety checks and an activity log.

**What it doesn't promise**
7SVEN is not a universal phone automation system. Accessibility support differs between apps, consequential communication actions may require manual confirmation, and Android battery policies can delay background tasks.

**Get started**
- Source: https://github.com/Ujexa/7SVEN
- Read `README.md` for build/setup requirements and limitations.
- Review `THIRD_PARTY_NOTICES.md` before redistributing binaries or models.
- Report reproducible bugs with Android version, device, permissions and exact steps.
